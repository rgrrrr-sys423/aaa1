# 방구차 깃발 게임

터미널에서 즐길 수 있는 간단한 턴제 방구차 게임입니다. 몬스터를 피하거나 방구 범위로 처치하면서 깃발을 먼저 획득하세요. 스테이지가 올라갈수록 몬스터 숫자와 이동 속도가 늘어나며, 스피드 업과 방구 범위 확장 아이템을 사용할 수 있습니다.

## 실행 방법
1. Python 3.10+ 환경을 준비합니다.
2. 저장소 루트에서 아래 명령을 실행합니다.
   ```bash
   python game.py
   ```
   고정된 스테이지 구성을 사용하려면 `--seed <숫자>` 옵션을 함께 전달하세요.

## 기본 조작
- `move <방향> <칸수>`: 현재 속도 이하로 이동합니다. 예) `move right 2`
- `use speed` / `use range`: 아이템을 사용해 3턴 동안 속도 +1, 5턴 동안 방구 범위 +1 효과를 얻습니다.
- `status`: 현재 체력, 속도, 방구 범위, 아이템을 확인합니다.
- `help`: 명령어 도움말을 다시 봅니다.
- `quit`: 게임을 종료합니다.

## 게임 규칙
- 방구차는 체력 3으로 시작하며 깃발을 차지하면 다음 스테이지로 이동합니다.
- 몬스터가 방구차에 닿으면 몬스터는 사라지고 방구차 체력이 1 감소합니다.
- 방구차 주변 맨해튼 거리 내(방구 범위) 몬스터는 자동으로 제거됩니다.
- 스테이지가 진행될수록 맵 크기와 몬스터 속도가 커집니다.
